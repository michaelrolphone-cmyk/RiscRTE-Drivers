# Shared alarm ready-step integration

The optional `--alarm-ready-drain` product selection routes to the owning System
foreground helper through System and Utilities builders. It is not a Badge-local
alarm algorithm. All nine selected foreground adapter clients receive the same
validated policy; Home and the unselected Timecard composition do not adopt it.

Qualification rejects missing, conflicting or untagged compile definitions and
checks the eight-millisecond between-phase policy against each actual receipt.
This budget does not preempt a slow synchronous provider callback. Existing
persistence, LOADING authority, input sampling, alarm acknowledgement and pending
work remain in force. Native Runtime and Home are unchanged in this cohort.

The accompanying NP RGB565 row helper is forced inline without removing its
validity, clipping, checkpoint or refresh checks. Owning parity tests and target
admission are distinct from physical FPS acceptance. Settings setup/cache and
callback-free batching experiments remain unselected; no Settings raster gain is
claimed from their host results.
