# Temporary Springboard Quick package qualification

The explicit `springboard_quick_actions` selection adds only the selected
Springboard preference grant; omission retains the historical grant policy.
The package reads the actual target Springboard recipe and verifies the existing
owning profile, exact definitions, mandatory namespace1, sliced presentation,
no radio controls, source pin and original pre-PSRAM-fix ELF identity.
This is temporary app-local composition, not resident architecture.

Selected packages require `local-quick-normal.json` and
`local-quick-sanitized.json` in software evidence. The ordered actual Runtime
cases are 34/37/38/40: explicit Save, retained copied-result fault, cancelled
pending frame plus returning Light, and alarm interruption/restoration.
The package recreates the current owning generator's three changed fixture
files and requires byte identity with the executed sources. Other shared inputs
must match the full sanitized cohort and all recorded files must still match.
This preserves the pending-frame/private receipt, terminal fault and restored
frame assertions; a missing local receipt is not a pass. Current runner receipts
lack a per-result returncode; the byte-verified runner checks subprocess success
before emitting results. The package does not fabricate a returncode field.

An optional `execution-normal-source-equivalence.json` (or sanitized counterpart)
may describe only the exact host-runner `-pipe` insertion and `-g` to `-g1`
change. It contains the original source text and hash, current hash, source path,
and historical execution receipt hash. The verifier independently reconstructs
that one change and rejects any other difference or unused equivalence. This
preserves a historical successful test; it is not a rerun or a target-code change.

Native provenance retains the clean pinned base IDF and separately modified
staged SPIFFS component. Packaging rechecks all staged source hashes and the
seven actual compile units with the uniform 64-entry ABI definition. Selected
performance tracing is checked against actual Runtime compilation definitions.
Neither check implies physical qualification. Native artifact hashes and exact
source locks remain mandatory.
