# Historical extraction qualification, 2026-10-24

This records the initial PR44 component baseline, not the current candidate.
Its facade ELF hash below predates the scoped-sync correction and contains
PSRAM-unsafe native CAS; do not use that artifact as qualified for PSRAM loading.
The current [Badge Home qualification](../../boards/waveshare-esp32-s3-touch-amoled-1.75c/home/README.md)
uses a rebuilt scoped-sync facade, real Runtime graph/activation and native link.
Current builders emit fresh source-bound receipts; historical results below are
retained for provenance and do not substitute for those receipts.

These are local source/component results on the Drivers extraction based on
`0a04382db4b6871a9e8298cbc964d4896e8b483a`. Hosted exact-head CI is a separate
receipt. The original unpublished `0161c20` tests are not substituted for these.

Inputs: Runtime `13eca114cb58469cf6004fafc3da84fbd9d29beb`, Watch
`605d5e7d4e2b46f6b33ff2f195582db6f882535c`, ESP-IDF
`fff9895c82d744c7237be8847347bdd1b07c6643`, GCC15.2.0
`esp-15.2.0_20251204`. SDK compile commands were generated by configuring the
actual Runtime IDF build. No substitute SPI/GPIO SDK declarations are used.

## Passed

- Facade: default rectangular, 1.75C round and independent offset/asymmetric-inset
  profiles, normal and ASan/UBSan. Full RGB565 frames, brightness, supply refusal,
  safe bounds, checked reset custody, sleep/rollback and retained cleanup.
- DCDC1: all 32 voltage codes and both enable states, read-only register behavior,
  malformed configuration, acquisition/read/release failures and retained retry.
- Real preparation + board adapter + CST9217: PMIC observation before reset,
  GPIO2-only 10/50ms reset, GPIO1 untouched, 18 preparation fault cases, CST probe
  acquisition/read/release failures, poll gaps, blocked quiescence and ordered
  consumer teardown. Normal and ASan/UBSan.
- Profile compile contracts: 8 valid and 43 invalid cases in each of C/C++, both
  host and Xtensa compilers.
- Actual-SDK native matrix: 12 host variants and 12 Xtensa objects across three
  geometries and trace/probe combinations, plus 30 explicit retained probe-timeout
  cases. Four invalid initialization programs rejected for host and target.
- Native ASan/UBSan matrix: all 12 host variants and retained timeout cases.
- Native staging: default, Badge and arbitrary profile, each host/target compile;
  real CMake selection with a second force-include and paths containing spaces;
  repeated includes do not duplicate source selection. Wrong SDK, mixed Arduino,
  competing backend, missing profile and overwrite attempts reject without
  altering existing inputs. Staged source, provenance, notice and license bytes
  match their recorded hashes.
- GCC15 provider ELFs: actual Runtime loader admission, Xtensa ET_DYN shape,
  sole `t5_driver_get` export and bounded import set. The touch-only startup
  adapter/preparation archive compiles as PIC Xtensa objects.
- Unchanged historical preservation checker, preparation/profile tests,
  CST9217 normal/sanitized regressions and migrated-driver documentation check.

## Explicit limits

LeakSanitizer is disabled because this ptrace-hosted environment cannot run it;
ASan/UBSan still execute. No full firmware link, admitted Runtime boot graph,
partition/storage/time policy, shared Watch provisioning or device test is
claimed. Physical orientation/touch agreement, raster visibility, voltage under
load, sleep/current behavior and later installation remain unqualified.

The inherited source/release parity defect is separate and unchanged by this
extraction. Historical driver sources, SDK, inventory, accepted release bytes,
candidates and preservation guards are not modified. The 2.06 repository is not
changed and does not yet consume the extracted component. No app fork is made.
