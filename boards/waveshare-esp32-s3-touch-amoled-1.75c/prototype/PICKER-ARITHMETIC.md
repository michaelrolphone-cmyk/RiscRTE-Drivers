# Native picker glyph arithmetic

The selected Watch source preserves native-size face rendering, preview cache,
all34 faces/five categories, animation, raw input and callback traversal.
An exact signed quotient/remainder recurrence removes per-pixel horizontal
64-bit division from glyph sampling. It does not scale completed frames or
quantize layout. Target stack use for the isolated function rises16bytes.

Independent integer-oracle and full/partial buffer plus ordered checkpoint
parity tests cover the selected source. Exact-target picker execution separately
covers full traversal, modeled slow display, allocation refusal/retry, malformed
reports and a distinct expected-retained terminal case. Product package gates
reject host-source substitutions, mixed target/source identities, missing lanes,
and any terminal result mislabeled ordinary success.

In the measured software rendering sample, horizontal long-division helper
calls decrease approximately98.2%; Y divisions and other rendering work remain.
Host elapsed timing showed no meaningful improvement. This is a target arithmetic
cost reduction, NOT a measured device-speed improvement or reported-crash fix.
The user's physical picker slowness/crash has not been reproduced or confirmed
resolved. Actual hardware input, timing, memory pressure and power remain untested.

The CI source cohort explicitly preserves the original Watch03aa baseline for
independent pixel/callback parity. Local qualification is not hosted CI or proof
of completed GitHub source delivery. Existing published cohorts remain immutable.
