# Native WiFi presentation

Select `--native-wifi-geometry` on this product's qualified `--quick-actions`
cohort. The standalone System `--watch-native-ui` option does not intrinsically
require Home QuickActions or a preference broker. Omitted selection preserves
legacy WiFi presentation. No new provider or authority is introduced.

Native drawing and hit testing share actual safe-content dimensions. The
physical 466-pixel panel has a 328-pixel safe-content view at offset 69; the
adapter applies that offset exactly once. Keyboard Page/Delete/Done and all
three character pages retain their meanings. Done changes the RAM draft;
Save explicitly persists existing namespace-6 credentials. Storage remains
plaintext, with the existing two-slot commit-selector protocol, not encryption
or the Home copied-preference broker.

Runtime qualification requires all 46 cases in normal and sanitized lanes,
including scan cleanup, nested navigation, all keyboard pages, explicit save/
forget, returning Light draft retention and an actual Countdown interruption
with durable acknowledgment and substantive restored editor. Network providers
and screen captures are modeled: association, RF, panel behavior and physical
sleep/wake remain unverified. No auto-connect or implicit draft persistence.
